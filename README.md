# GitHub Profile Analyzer

A simple and fast web tool for analyzing GitHub profiles.

## ✨ Features

- 👤 GitHub profile information
- 📦 Public repository count
- 👥 Followers and following
- ⭐ Total repository stars
- 💻 Programming languages
- 🏆 Top repositories
- 🔗 Direct GitHub profile link
- 📱 Mobile-friendly design

## 📖 How to Use

1. Enter a GitHub username.
2. Click **Analyze**.
3. View the user's profile information.
4. Explore repositories, stars, and programming languages.

## ⚡ GitHub API

This project uses the public **GitHub REST API** to retrieve profile and repository information.

No backend or database is required.

## 📱 Responsive Design

The project works on both desktop and mobile devices.
